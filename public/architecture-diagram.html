Gate transaction

Code inspection is read-only; a gate operator completes identity review and check-in.

IssueAuthorized user creates a visit and receives a six-digit code.
InspectServer checks code status and expiry; inspection does not consume it.
ReviewOperator follows site identity and entry procedures.
Check inBadge and gate event are recorded; the code cannot be reused.
Check outDeparture is recorded against the visit.
